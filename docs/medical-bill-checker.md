# Medical Bill Checker (phase 2)

Route: `/tools/medical-bill-checker`. Not linked from the homepage and not in `sitemap.xml` until the tool is fully working (the featured card stays "Coming Soon"). Payment is not implemented.

## One-time setup (required before typecheck, tests, or build)
`package.json` now declares `tesseract.js` (^6.0.1) and, as a dev dependency, `@tesseract.js-data/eng` (^1.0.0). **`package-lock.json` has NOT been updated**, because it can only be generated by running npm. Until it is regenerated, `npm ci` fails with an out-of-sync error. Run this in Codespaces and commit the result:

```
git fetch && git checkout feature/medical-bill-checker && git pull
npm install
git status                      # package-lock.json should show as modified
git add package-lock.json
git commit -m "chore: update lockfile for tesseract.js"
git push
```

`npm run ocr:assets` (runs automatically before `dev` and `build`) copies the worker, the four WASM core variants, and `eng.traineddata.gz` into `public/ocr/`. That folder is git-ignored and regenerated on every build.

## How OCR runs
- Tesseract.js is a dynamic import (separate chunk), fetched only when the user taps "Read text from my scan".
- `createWorker('eng', 1, { workerPath: '/ocr/worker.min.js', corePath: '/ocr/core', langPath: '/ocr/lang', workerBlobURL: false, cacheMethod: 'none', gzip: true })`. All files come from our own origin. Nothing is written to IndexedDB. Images are passed in memory.
- `recognize(image, {}, { text: true, blocks: true })`; progress is the engine's real `recognizing text` progress. Cancel terminates the worker.
- Every drafted value starts **unchecked**. Unchecked scanned lines count as "Needs review" and unchecked scanned totals as unreadable, so they are excluded from confirmed checks until the user checks or edits them.

## Config changes
- `public/_headers`: `Permissions-Policy: camera=(self)`; CSP `script-src 'self' 'wasm-unsafe-eval'`, `worker-src 'self'`, `img-src ... blob:`, `media-src 'self' blob:`, `connect-src 'self'`; `/ocr/*` cached 7 days.
- `public/_redirects`: rewrites the tool route to `index.html` (the existing `404.html` otherwise disables Pages' SPA fallback).
- `package.json`: dependencies above and scripts `ocr:assets`, `predev`, `prebuild`.

## Known limitations
- Not yet run against real bills; accuracy and the parser's coverage are untested. The parser expects one amount per labelled line and US month/day/year dates.
- Overlapping pages can produce the same line twice; the duplicate check shows it as "possible duplicate — verify" with page numbers.
- Findings about unchecked scanned lines say "unreadable or missing an amount" (slightly narrower than the real reason).
- No PDF export, payment, privacy policy/terms, EOB reading, edge detection, or PDF/HEIC input.
