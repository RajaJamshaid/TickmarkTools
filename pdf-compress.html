Frequently Asked Questions

Is it free?

Yes.

How much smaller will my file be?

Savings vary by PDF — documents with redundant structure benefit more than image-heavy scanned PDFs, which need image re-compression for large gains.

Is quality affected?

Text and vector content are unaffected; this optimizes file structure rather than re-compressing images.

Why is my PDF so large?
Usually due to high-resolution embedded images, unused fonts, or redundant internal structure.
Does compressing reduce PDF quality?
This tool optimizes internal file structure without touching visual content, so quality is preserved.
What's the best way to shrink an image-heavy PDF?
Compress the images before creating the PDF, or use a dedicated image-recompression tool for maximum reduction.
