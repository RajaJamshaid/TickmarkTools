How does image compression work?
It reduces file size by re-encoding the image at a lower quality setting, discarding some data that's less noticeable to the eye.
Will compressing reduce image quality?
Slightly, depending on the quality percentage you choose — higher quality keeps more detail but a larger file size.
What's the best quality setting for web use?
70–85% quality is usually a good balance between file size and visual quality for websites.
