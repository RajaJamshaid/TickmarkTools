How to use the PDF Split

  1. Click the upload box and select the PDF file you want to split.
  2. Enter the From and To page numbers for the range you want to extract.
  3. Tap Split PDF, then download the new file containing just those pages.
  4. Use the Copy or Share buttons to save or send your result.
💡

Tip: Once you upload a file, the To field automatically fills in with the last page number — you only need to adjust the range to what you actually want.

Common mistakes to avoid

  • Entering a page number higher than the document actually has.
  • Setting the From page higher than the To page by mistake.
  • Forgetting that page numbers here start at 1, not 0, matching how PDF readers display page numbers.

How PDF Split Works

Extracting a page range, client-side

This tool reads your PDF in the browser using the pdf-lib library, detects the total page count, then copies only the pages within the range you specify into a brand-new PDF document. The original file is never modified or uploaded — only the extracted pages leave your device, as a fresh downloadable file.

When to use this tool

Use it to pull a single chapter out of a longer report, extract just the signature page from a contract, or separate one section of a scanned document from the rest.

✓ Pros

  • Works instantly, right in your browser
  • Auto-detects the total page count so you know the valid range immediately
  • No sign-up, no ads blocking the result

✕ Limitations

  • It extracts one contiguous page range per split — it doesn't support picking several separate, non-adjacent ranges in one pass.
  • Very large PDF files depend on your device's available memory, since everything is processed in the browser.
  • Heavily encrypted or restricted PDFs may not load correctly, since some protections block programmatic access.
🧩

Splitting Into Multiple Files

Extracting more than one range

This tool extracts one page range at a time, producing a single new PDF. If you need several separate files from the same source document — for example, pages 1-5 as one file and pages 6-10 as another — simply run the tool again with the second range after downloading the first. Your original uploaded file stays untouched between runs, since nothing is modified in place.

Splitting into several files

  • Run 1: upload the file, set From 1 / To 5, split, download.
  • Run 2: re-upload the same file, set From 6 / To 10, split, download.
  • Repeat for as many ranges as you need — each run produces one independent PDF.

Splitting vs. Merging

Splitting and merging are opposite operations: splitting takes one PDF and extracts part of it into a new, smaller file, while merging takes several PDFs and combines them into one larger file. If you've split a document into pieces and later want to recombine some of them — or combine pages from entirely different documents — TickmarkTools' PDF Merge tool handles that in the same browser-based, upload-free way.

Accuracy & limitations

This tool extracts page ranges accurately, but it's worth knowing the boundaries:

  • One range per run. It extracts a single contiguous page range at a time — run it again for additional, separate ranges.
  • Memory-bound. Because everything runs in your browser, very large files depend on your device's available memory.
  • Some protected PDFs may fail. Heavily encrypted or restricted PDFs can block programmatic access even with encryption-tolerant loading.

PDF Split FAQ

Is this PDF split tool free to use?

Yes, the PDF Split is completely free with no sign-up required.

Are my PDFs uploaded to a server?

No — splitting happens entirely in your browser using client-side technology; your files never leave your device.

How do page numbers work here?

Page numbers are 1-based, so page 1 is the first page — this matches how page numbers are typically displayed in PDF readers.

Can I extract several separate ranges at once?

Not in a single pass — run the tool again with a different range for each additional piece you need.

Will splitting affect PDF quality?

No, page content is copied as-is without re-compression, so quality is unchanged.

Does this tool store or upload my data?

No. All calculations run entirely in your browser, and nothing you enter is ever sent to a server or stored.
