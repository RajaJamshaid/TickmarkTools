PDF Split

Extract a specific page range from a PDF into a brand new document.

How to Use PDF Split

  1. Upload your PDF file.
  2. Enter the page range you want to extract.
  3. Click Split PDF.
  4. Download the new PDF containing just those pages.

Frequently Asked Questions

Is it free?

Yes.

Can I extract non-consecutive pages?

This tool extracts a continuous range; for scattered pages, run it multiple times.

Is my file uploaded anywhere?

No, splitting happens entirely in your browser.

🤖 Ask AI about this tool

Tap a question for an instant answer. Full conversational AI is coming soon.

How do I know my PDF's total page count?
Open your PDF in any viewer — the page count is usually shown in the toolbar or status bar.
Can I split a PDF into multiple separate files?
Yes, run this tool multiple times with different page ranges to create separate files.
Does splitting affect PDF quality?
No, page content is copied as-is without any re-compression.
